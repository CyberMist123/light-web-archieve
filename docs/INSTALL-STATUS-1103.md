# 首次安装 + 状态显示：需求与问题清单（1103，待作者定稿）

起因：作者在干净 Win11 虚拟机里实测 PR 91，界面割裂、满屏「还不能用」、显示和实际矛盾。
后端实测是好的（link-brain 0.2.1、读取组件、认字都就绪，VC++ 运行库已补），问题在前端显示和流程顺序。

## 一、作者已定的需求

1. **只有一套安装流程**：首次启用 → 打开设置页「懒人安装」那一块（上面选项、下面一条总进度）+ 一条通知「点这里看进度」+ 状态栏一行进度。
   不要单独的安装弹窗（PR 91 的 installer-ui.js 弹窗去掉，或者只做成跳到懒人安装的入口）。参照 VS Code 扩展的「开始使用」清单页 + 状态栏进度。
2. **一下子就能定的，装的时候选**（都有默认值）：收藏放在哪 · 同步哪些平台（小红书 / B 站）· B 站同步哪些收藏夹 · 认图片里的字（默认开）·
   视频说话转文字（约 2 GB，**待作者确认：默认不勾？**）· B 站画质 / 超过多长先不下。
3. **可以慢慢来、不挡路的**：扫码登录小红书 / B 站、AI key。用到时提示一次；没打开的功能不显示「还不能用」。
4. **小红书和 B 站同步同时跑**（不同网站、不同账号）。
5. **目录先生成**：同步开始前先出目录页（显示「正在同步 3/50」），边同步边刷新。
6. 正在下载的东西要看得见（「正在下载认字模型 80 / 139 MB」），不是等文档冒出来才知道。
7. 防御性说明大幅减少：只有「打开了但还缺东西」的功能显示一句话 + 一个按钮。

## 二、状态没有唯一真相（两路只读排查的结论）

现在「装没装好」和「运行状态」各有约 10 个独立来源，各显示点各取一个，刷新时机也各不相同：

- 功能状态：缓存的 `setup plan`（一个会话只在少数时点重读）· 插件设置里的开关当「装了」用 · 后端 `setup check` · 安装窗口自己的状态 ·
  `usage` 的 AI 路由（60 秒缓存）· `doctor` · `currentBackend()` · 账号缓存（10 分钟）。
- 运行状态：插件内存 `running`（重启就丢）· `setup-run.json` · `sync-status.json` 等文件 · 账号缓存 · B 站实时 CLI · 问题汇总文件 vs 实时列表 · Python 自己的文件锁。

### 新用户头几个小时最容易碰到的矛盾（按概率排）

1. **装好了还说没装**：安装窗口在后端刚装好时读了功能清单（这时读取组件、认字还没装），之后装好了不再读；`setup run` 的装组件阶段也一样，要等几小时的同步跑完才重读。
   识图那一行的「现在」甚至清单刷新了也不重画。设置页顶部提示画一次就不动（停在「正在安装 12%」）。
2. **「在底部状态栏停止 / 看进度」**：所有忙碌提示都这么说，但状态栏默认是隐藏的（`devSyncLog: false`）。
3. **同步期间没有目录页**，旁边的「刷新目录」按钮又被「正在跑」挡住（刷新目录是纯本地操作，有自己的文件锁，不需要插件那把大锁）。
4. **B 站「预估 / 立即同步」整段灰掉、不说为什么**，提示却叫你去点。B 站和小红书互不相干，不需要互斥。
5. **同一次同步，设置页三种说法**：懒人安装卡片显示原始日志尾巴、同步那一行显示篇数、状态栏只有阶段名。
6. 首次自动跑期间，点向导的完成按钮 / 扫码登录会撞锁或问「停止装好并跑完？」。
7. **安装窗口扫码失败也显示「✓ 已登录」**（判断写成 `r.ok !== false`，但登录结果没有 `ok` 字段）；设置页账号卡片还用 10 分钟前的缓存。
8. 账号卡片的「刚刚确认」时间画一次就不动。
9. Obsidian 重启后：插件忘了有任务在跑，按钮全部恢复，能再起一个同步甚至第二个 `setup run`。
10. 后端把「开关关着」算成「没装全」（认字关着 → partial），前端再说成「没装好」；「AI 能不能用」有 4 套判断规则。
11. 问题数在两行设置、目录角标、问题面板里说法不一。

## 三、改法方向（待定稿后再动手）

1. **一个状态中心**（插件内一个对象 + 一个事件）：功能状态、运行任务、账号、同步进度都从这里读；任何来源一变就更新它并通知所有显示点重画。
   显示点不再各自缓存、各自刷新。
2. **后端每装完一个组件就推一条结果**（`{stage:'install', component, status, check}`），前端立刻更新状态中心，不等整轮跑完。
3. **「装没装」和「开没开」分开**：后端 check 只报装没装；开关由设置决定；前端「没开 = 不显示」。
4. **锁拆开**：小红书账号类任务一把（Python 已有 account_session）、B 站一把、刷新目录不用插件锁；重启后从 `setup-run.json` 恢复「有任务在跑」。
5. **状态栏默认显示一行进度**（不再藏在开发选项里），所有「去状态栏看」的提示才说得通。
6. **目录先生成、边同步边刷新**；同步进度统一一种说法（「已存 12 篇 · 剩 38 篇 · 约 17:20 读完」）。
7. 修安装窗口登录误报；账号卡片随登录 / 同步事件刷新。
