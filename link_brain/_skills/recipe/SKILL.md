- 第一行：菜名 + 一句关键（口味 / 难度 / 最关键的一步或配比），配比、克数、时间、火候一律照原文数字。
- 「食材」列表：主料、调料分开；用量帖里没写就写「适量（帖里没写用量）」，不要自己补。
- 「步骤」有序列表：一步一行，顺序、时间、温度写进去；帖里步骤不全就明说「帖里步骤不全」，不能拿常识编成完整菜谱。
- 「要点与避坑」≤5 条：评论区里的实测、替换建议并进来，行首标「评论区·昵称」，不能说成作者说的。
- 问「哪里买材料」：只写帖里 / 评论里点名的店、超市、平台和价格，价格后注「帖子所述，发帖日期 X」，不编超市。
- 多道菜（盘点）：每道一行「菜名 —— 一句为什么 · 出处」。
