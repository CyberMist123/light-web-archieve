（陈列纪律参考 anthropics/skills 的 frontend-design，Apache-2.0；只取审美与排版原则，不含任何代码）
- 先定一个审美方向，用她的原话写在最上面（例「克制、低饱和、留白多」）；所有挑选和描述都服从它。
- 陈列单位 = 一个灵感对象：**名字** —— 它好在哪一点（具体到配色 / 版式 / 交互 / 字体中的哪一样）· 能借鉴到哪里 · 出处。
- 分 4–7 组，组名描述「用途」而不是「来源」（例「首页大标题」「深色界面」「小动效」）；每组 3–8 个，宁缺毋滥。
- 不写「很好看」「值得参考」这类空话；同质的只留最典型的一个，其余并进一句「类似的还有 …」。
- 她要做成页面时：这一份清单就是陈列页的数据（类别 / 条目 / 先看这几个），页面由程序渲染，不在回答里写 HTML。
