# 1101 B 站「挑要下的视频」页

分支 `claude/peaceful-borg-b1a17b`（基于 `f862fc5`），**未部署**，没连 B 站（全是假数据）。
作者原话：「应该是打钩下载，但打了勾划掉了，是删还是要下呢，很迷惑，而且不能默认 user 会用命令行……做成封面页一样的显示模式，也可以切换目录显示」；
再改：「不是一个个点，是复用目录的瀑布流 / 目录切换，选中，下载。其他不下载或删除，不加入收藏，放回收站。也不要说太长，具体数字，几小时几分钟、分几 P」。

## 入口

- 设置 → ② 收藏与同步 → B 站：主按钮「挑要下的视频…」（先跑 `bilibili pending` 重写页面 / 脚本 / 数据——只读本地，部署后不用等同步就是新版——再按页头 `lb-page: bili-pending` 打开）。
- B 站同步完的提示：有等着挑的就带按钮「挑要下的视频」；设置页「上次」那一行的链接也是它。
- 命令面板「B 站：挑要下的视频」。
- `Web/Bilibili/B站待选清单.md` 只剩一句话 + `[[B站挑选|挑要下的视频]]`（不再列条目、不让打勾、不提命令行）。

## 页面

封面卡片（16:9、B 站样式的底部渐变条：左「6P」右「5:05:00」）；卡片下「5 小时 5 分 · 分 6 P · 去 B 站看」、UP · 收藏夹 · 收藏日期。
顶上「瀑布流 / 目录」切换（同回收站 / 目录页的叫法）、收藏夹下拉、全选。点卡片 = 选中（左上角圈）。选中后顶上一条：
「已选 N 个 · 一共 X 小时 Y 分」+「下载」「删除」「取消选择」（选中的里有点过下载的，多一个「不下了」）。
- 下载 → `bilibili choose --allow`；卡片标「要下」，顶上出「点了「下载」的 N 个，下次同步时下载」+「现在开始下载」（= 设置页「立即同步」同一个互斥任务）。
- 删除 → 确认框 →`choose --deny`（写删除屏蔽 → 回收站「记录」里有、能重新导入；以后同步不再列）；提示带「撤销」（`--undo` + 回收站 `forget`）。
- 没存上：「没保存上，内容还在，可重试：<原因>」，选中的都还在。
- 下好了的多 P 灰一点、不能选；所在收藏夹都关了的写明「点了下载也不会下」。手机上只能看。

设置页原「挑选要同步的…」弹窗只剩收藏夹开关（「选同步哪些收藏夹…」），逐条勾视频的部分拿掉了。
