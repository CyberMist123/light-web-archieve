## 待她：在 Obsidian 里过一遍（真库只读也行，不碰会改数据的那几个）

部署后（插件拷进 vault、`python -m link_brain catalog` 重建目录页脚本）：

1. 打开设置 → Link Brain Actions：左边 01–06 六个锚点，点「04 高级功能」滚过去、那一项变粗；把设置窗口拉窄到一半，锚点变成顶上一条横排。
2. ① 小红书卡：名字 + ✓ 已登录（N 分钟前确认），右边「换个账号」（**别点**，点了会退出再扫码）；B 站灰着。
3. ② 「同步」开关和你现在的计划任务一致（开着）；「同步时间」显示「当前：每天 04:00」（或你现在的规则）。**会改计划任务**：想验自动存就把时间改成别的、停手两秒，看到「已保存：…」，再改回原来的；不想动就跳过。
4. ② 「＋ 更多」点开：收藏放在哪 / 登录后马上同步 / 每次新收上限 / 补评论间隔 / 下载文件夹几项都在。
