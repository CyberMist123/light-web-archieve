## 自动化

`node tests/test_cite_jump_1026.cjs`（假右栏：复用、先切文件后画、新打开取消上一次没画的）逐项：

- (来源1, 段2) 两处合并成一个，段1 / 段3 各留；只显示来源号；`aria-label`。
- 悬停卡片 = 点击目标（段2 · 图片文字 图2）；对不上时写「点了只打开原帖」；悬停不打开原帖。
- 多图段号：段2 → `image-002`、段3 → `image-001`、段1 → `para:0`。
- 评论 c5.1：折叠的 details 打开，`target = comment:c5.1`。
- A → B：B 画好前右栏还是 A 的 DOM，结果 `shown = xhs-b`、`target = image-101`、`waitMs ≥ 200`。
- 快速连点 B → old → A：右栏文件、`data-lb-item`、日志、高亮都落在 A 图2；同一拍 B / A / A：中间那次没去开 B。
- 老帖没有 `data-lb-item`：不把 A 的旧 DOM 当老帖（`waitMs ≥ 200`、`target = para:0`）。
- 失败诚实：没段号不沾边 `no-match`；指定图3（没画）`not-found` 且没落到图1；段号不存在 `seg-missing`；旧答案同号两段 `seg-ambiguous`；失败时原帖照样打开。
- 历史回答没段号、上下文唯一 → 照跳；旧答案同号两段但上下文分得出 → 跳对。
- 来源标题只打开、不写定位日志。

另：`tests/test_cite_seg_1021.cjs`（胶囊文字改为来源号，断言 `aria-label`）；`tests/test_ask_board_1020.py`（拆图后段号 1..4 各不相同；assets 倒序时按文件名对上）。

## 体验预算（RELEASE-BAR §2）

「用户点的每一个操作有明确结果」：点引用要么跳到、要么一句话说明原因并打开原帖；不再静默跳错封面、不再「再点一次才好」。等待上限（12 秒）不变，只是等的条件对了；悬停不触发任何打开。
