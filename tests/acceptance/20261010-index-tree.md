## 待她：一步

1. 重载 Obsidian（或第三方插件里 Link Brain 关掉再打开）→ 打开目录：顶部分类和昨天一样（「其他」改叫「未归类」）；点一个大类，下面一行是二级小标签。
2. 点「索引」看分叉树；横幅「AI 起草了一版」→「看草稿」→ 满意点「用这版」（先备份）；不满意就不管它。
3. 想改就点「编辑索引」直接改 索引.md，保存后几秒目录跟着变；「未归类建议」里点「加入」才写进去；设置 → 收藏与同步 →「目录分类（索引）」是同样几个入口。
4. 给想要 wiki 的节点行尾加 `[wiki]`，索引图里那个节点点「生成」（先报价）。
